## 一阶段
选择一个模型家族，训练就是让模型在这个家族里寻找最佳参数，比如
* 线性模型空间 y=wx+b
* 二次线性模型空间 y=ax^2+bx+c

神经网络为什么厉害，因为它把模型空间放大了
* 以前 y=wx+b 只能画直线，但它可以叠加几十层，里面有几万、几十亿参数
* 于是就变成，人只定义结构，机器自己寻找规律，你不会告诉模型猫耳朵长度是多少，猫胡须几根，而是直接给几百万张猫图，让神经网络自己调整参数

模型家族
* 直线、二次曲线
* 线性回归
* Logistic Regression
* 决策树
* 随机森林：投票机制
* XGBoost

深度学习家族
* MLP 全连接网络
* CNN 专门处理图片
* RNN 专门处理序列，例如文本、语音
* Transformer Embedding->Attention->MLP->Attention 不断堆叠

机器模型两阶段：选择模型家族，然后优化参数。工业界一直在寻找更强的模型家族，历史就是线性模型->决策树->随机森林->XGBoost->神经网络->Transformer。

传统机器学习，需要你先猜直线、抛物线、树，而神经网络只需要给足够多参数，它自己学，根据 Universal Approximation Theorem 理论，一个足够大的神经网络可以逼近几乎任意函数。所以现代 AI 的历史，本质上是手工挑模型家族，神经网络统一模型家族，Transformer 成为主流模型家族。

机器学习需要线给定模型家族，如果模型家族不对，则很难拟合，但现实世界很复杂，你根本不知道规律长什么样，因此无法提前给定模型家族。神经网络的思路就是既然不知道公式，那就不猜公式了，直接构建一个超级大的函数空间，如 y=σ(wx+b)，这里 σ（激活函数）和 b（偏置）。

假设我们选定模型（感知机）为 y=wx+b，但如果我们将多个感知机（神经元）拼起来呢，听起来很合理，但你会发现它依旧只能表示直线。但如果我们在神经元后面加一个非线性变化，也就是激活函数，于是表达能力暴涨。

> 没有激活函数，多层则毫无意义，因为本质上还是单层。

在神经网络中可能有成千万个参数，我们不可能手动推导 Loss -> Gradient，于是就是需要深度学习中最核心的技术，反向传播（Backpropagation），它自动计算每个参数应该往哪个方向改，改多少，如果梯度下降是神经网络的发动机，那么反向传播就是变速箱。

反向传播的本质比名字简单的多，就是利用链式法则，把最终 Loss 对每个参数的影响一层层传回去。反向传播某种意义上就是：最终结果错了多少 -> 是谁导致的 -> 每层分一点责任。

神经网络的训练其实根本不是 AI 理解了什么，而是谁导致了 Loss 变大，给谁分责任，按责任大小调整参数。

在深度学习中，输入数据尺度太大时，梯度可能巨大，训练会不稳定，所以甚至数据经常会做数据归一化/标准化，也就是把 100，30 这种数据缩放到类似 1.0，0.3 这种。

> 对谁求导，就把其他变量都当常数，只关心对该变量有反应的部分。

梯度消失：在深层网络中，随着链式法则连续相乘，梯度越来越小，前层参数学不动，尤其是第一代激活函数 Sigmoid，它的特点是导数最大只有 0.25，很多时候是 0.01，0.001 甚至更小，这也是为什么 ReLU 激活函数伟大的原因。于此同时还有个对应问题，叫做梯度巨大。

到目前为止，已经了解了 MLP，按照深度学习发展历史，后面就是
* 发展史路线：MLP -> CNN(图片)-> RNN(序列) -> Attention -> Transformer -> GPT
* 大模型路线：文本 -> Tokenizer -> Embedding -> Attention -> Transformer -> GPT

从头学可以理解为什么 Transformer 伟大，为什么 Attention 会出现以及 RNN 为什么会淘汰，但需要花时间学一些过时的架构，推荐直接从大模型路线开始学习，能更快理解 GPT。
